# Model Card：道路事故严重程度与派单优先级

## 模型与用途

| 项目 | 内容 |
|---|---|
| 注册模型 | `road-severity-model` v5，复核时为 `production` |
| 训练 run | `4557265462694f7dbd9b1836225a0d7c` |
| 模型 | LightGBM 二分类器，随模型保存特征预处理与两条分级界线 |
| 预测目标 | 英国 DfT 已记录伤人事故中发生致死或重伤的风险 |
| 输入 | 226 个事故、天气、车辆及伤亡人员字段。事故时间和经纬度必填 |
| 部署输出 | `predict_proba` 返回伤情加权训练后的**原始分数**。`predict` 按原始界线分为一级立即、二级紧急、三级常规 |
| 分级界线 | 原始分数低于 0.2198 进入三级，达到 0.6864 进入一级。服务使用模型中保存的完整精度 |

模型用于辅助确定已报告事故的核实和派车顺序。一级组中约 58.3% 的事故在官方记录中为致死或重伤，约 22.0% 达到按细分伤情定义的危及生命程度。最终处置需结合现场信息与调度员判断。训练样本仅包含已发生的伤人事故，无法估计普通道路时段的事故发生率。

## 数据与验证

英国 DfT 2024–2025 年事故、车辆、伤亡记录按事故编号关联，再匹配天气。标签取 `collision_severity` 中的致死或重伤。`enhanced_severity_collision` 用于训练加权与分级验收，由特征管线排除。预处理在训练集拟合。

| 切分 | 时间 | 事故数 |
|---|---|---|
| 训练 | 2024-01-01 至 2025-06-14 | 115,535 |
| 验证 | 2025-06-15 至 2025-09-24 | 24,636 |
| 测试 | 2025-09-25 至 2025-12-31 | 24,679 |

冻结测试集上的 PR-AUC 为 **0.5060**，ROC-AUC 为 **0.7415**。原始阈值 0.5 下，精确率为 0.4502，召回率为 0.5829，F1 为 0.5080。部署分数的 Brier 为 0.1874，ECE 为 0.1449。

| 测试集验收项 | 项目要求 | v5 实测 |
| --- | --- | --- |
| 危及生命事故进入三级 | ≤ 5% | 3.79% |
| 致死事故进入三级 | ≤ 1% | 0.27% |
| 三级占全部事故 | ≥ 20% | 25.82% |
| 一级中危及生命事故的富集倍数 | ≥ 3 倍 | 3.52 倍 |

## 概率尺度与解释

伤情加权使原始分数与实际发生频率存在偏差。离线校准在验证集较早时段拟合候选方法，按较晚时段的 log-loss 选中 sigmoid，再用全验证集重新拟合。冻结测试集的 ECE 降至 **0.0076**，Brier 降至 **0.1618**。0.1275 / 0.4608 是该离线实验在校准尺度上的界线。当前 API 和单样本 SHAP 对应上表中的原始模型与原始界线。

SHAP 贡献的单位是 log-odds。v5 测试样本中，车辆及驾驶员信息（含碰撞过程）占平均绝对贡献的 46.53%，伤亡人员信息占 27.85%。未知编码和字段缺失可能反映填报方式，使用解释时需保留这一限制。

## 适用边界

- 总体验收基于完整现场信息。同时缺少车辆与伤亡信息时，v5 约 93.1% 的样本集中在二级。单独缺少伤亡信息时，致死漏判率约 1.1%，高于项目 1% 的参考线。
- 在单维切片中，城市组危及生命漏判率为 4.94%，乡村组一级富集为 2.85 倍。统计覆盖城乡、光照、限速和时段。驾驶员与伤亡人员的居住地贫困指数也可能引入地区偏差。
- Evidently 标记了 225 个字段中的 13 个，涉及季节性气象与部分车辆、道路字段。影响跨年度、跨地区外推的误差尚待独立数据验证。
- 公开数据缺少撞击速度、安全带及安全气囊状态。分级只用于辅助排序，不得作为个体伤情诊断、理赔或司法定责依据。
